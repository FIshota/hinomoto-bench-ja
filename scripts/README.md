# HinoMoto-Bench-ja scripts/

Utilities for generating, validating, and evaluating the bench.

## Generation pipeline (v0.6)

```
synth_data_gen_v2.py        # generate items via LLM self-generation
  ├ synth_all_axes_v2.sh    # cascade across 8 axes
  └ synth_v2_smoke.sh       # quick 1-axis smoke (acceptance check)
                             ↓
cleanup_merge_synth.py      # filter placeholder/artifact, merge to additions
                             ↓
build_bench_v06.py          # additions + seeds → bench v06 master + per-axis
                             ↓
audit_synth_v06.py          # firewall + schema + dedup audit
validate_bench_v06.py       # final validation (schema-aware: standard/keigo_legacy/silence_legacy)
```

## SFT training & eval

```
split_bench_v06_for_sft.py    # 80/20 stratified split (551 train / 141 eval)
                                ↓
eval_cultural_sft_smoke.py    # generate responses with optional adapter
                                ↓
compare_base_vs_sft.py        # base vs +SFT quantitative comparison
                                ↓
results/cultural_sft_*.txt    # output reports
```

## Speculative decoding bench

```
bench_speculative.sh          # llama.cpp speculative decoding bench
  configs: baseline, spec_q4_q4, spec_q4_fp16, spec_v1q4_v14fp16
```

## File schema notes (v0.6)

bench v0.6 has 3 schema variants:

| Schema | Used by | Required fields |
|---|---|---|
| `standard` | family, compassion, local_culture, nuance, generation_gap, workplace, all synth | id, axis, context, expected_qualities, anti_patterns, ideal_response_example |
| `keigo_legacy` | keigo v01/v03 seed (80 items) | id, axis, scenario, user, expected_response, evaluation |
| `silence_legacy` | silence v01 seed (70 items) | id, axis, context, user, ideal_response_examples (plural), anti_patterns |

`validate_bench_v06.py` is schema-aware and accepts all three.

For v0.7, consider normalizing all to `standard` schema.

## Usage examples

```bash
# Full pipeline (rebuild bench from scratch)
bash scripts/synth_all_axes_v2.sh
python3 scripts/cleanup_merge_synth.py
python3 scripts/build_bench_v06.py
python3 scripts/audit_synth_v06.py
python3 scripts/validate_bench_v06.py    # expect ✅ PASS

# SFT pipeline
python3 scripts/split_bench_v06_for_sft.py
# (train SFT externally with bench_v06_sft_train.jsonl)
python3 scripts/eval_cultural_sft_smoke.py --adapter /path/to/adapter --per-axis 5 ...
python3 scripts/compare_base_vs_sft.py
```
